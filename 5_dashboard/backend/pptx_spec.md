## 섹션별 상세 스펙

### 헤더 영역
- 배경: `#1E3A5F`
- 제목: "WW__ 품질 예측 불량 보고서" (흰색, 22pt, bold)
- 우측 상단: "대외비" 버튼/뱃지 (빨간 배경)

### 부제목 영역
- 배경: `#2A4A6F`
- 줄 1: "예측 불량 비율 임계값 y_pred ≥ 0.003412 · Val RMSE {rmse}" (빨간색 강조, 14pt)
- 줄 2: "Two-Stage 모델 · Val RMSE {val_rmse} · Test RMSE {test_rmse} · 상위 5개 피처 SHAP 분석 및 공정 개선 방안 수립" (흰색, 11pt)

### 섹션 탭 헤더
- 좌: `[ Modeling 현황 ]` — 배경 `#1E3A5F`, 흰색 텍스트, 14pt bold
- 우: `[ 불량 Unit 분석 현황 ]` — 배경 `#1E3A5F`, 흰색 텍스트, 14pt bold
- 두 탭 사이 구분선 명확히

## 왼쪽 컬럼: Modeling 현황

### 1. 분석시점 / 예측시점 텍스트박스
- 배경: `#1A3050`
- 내용:
  - `분석시점: {오늘 날짜}` (흰색, 11pt)
  - `예측시점: {오늘 날짜 +2달}` (흰색, 11pt)
- **이미지박스와 완전히 분리된 독립 영역**

### 2. 모델링 결과 텍스트박스
- 배경: `#1A3050`
- 내용: `모델링 결과: {meta.model}` + Val RMSE, Test RMSE 수치
- **이미지박스와 완전히 분리된 독립 영역**

### 3-A. SHAP 그래프 이미지박스
- 배경: `#3A5A8F`
- 라벨: "SHAP value 분석 결과 (shap분석 그래프)" (연한 파란색, 10pt)
- 내용: **빈 박스** (플레이스홀더) — 추후 이미지 삽입용
- **텍스트 설명과 완전히 분리**

### 3-B. Trend 그래프 이미지박스
- 배경: `#3A5A8F`
- 라벨: "(trend 그래프)" (연한 파란색, 10pt)
- 내용: **빈 박스** (플레이스홀더) — 추후 이미지 삽입용
- 3-A와 나란히 배치 (좌우로)
- **텍스트 설명과 완전히 분리**

### 4. SHAP분석 관련 결과 텍스트박스
- 배경: `#1A3050`
- 내용: `analyze_features` top features 수치 요약
  - 예: "X178_mean: HIGH 5.001 vs MED 4.999 (1.0x, p=0.001)"
  - TOP 3~5개 feature
- **이미지박스(3-A, 3-B)와 완전히 분리된 독립 영역**

### 5. Model RMSE 텍스트박스
- 배경: `#1A3050`
- 내용: `Model RMSE: {val_rmse}` (흰색, bold)
- **독립 영역**

## 오른쪽 컬럼: 불량 Unit 분석 현황

### 1. 대형 이미지박스 (상단)
- 배경: `#3A5A8F`
- 라벨: "이미지 박스" (연한 파란색, 10pt)
- 내용: **빈 박스** (플레이스홀더) — LOT 트렌드 또는 불량 분포 이미지 자리
- **텍스트 설명과 완전히 분리**

### 2-A. Position 버튼 (4개, 세로 배치)
- 스타일: 둥근 모서리 버튼, 배경 `#4A7AB5`
- 내용: `Position 1` / `Position 2` / `Position 3` / `Position 4`
- 흰색 텍스트, 11pt

### 2-B. 웨이퍼맵 원형
- 스타일: 원형 도형, 배경 `#3A6A9F`
- 라벨: "웨이퍼맵" (흰색, 11pt)
- Position 버튼 오른쪽에 배치

### 2-C. 피처임포턴스 박스
- 배경: `#1A3050`
- 라벨: "피처임포턴스 :정상vs불량 사이 그룹 분포차이" (연한 파란색, 10pt)
- 내용: `get_importance` top 5 feature를 텍스트 바(bar) 형태로 표현
  - 예: `X178_mean ████████ 304`
- 웨이퍼맵 오른쪽에 배치
- **이미지/그래프 영역과 완전히 분리된 텍스트+바 영역**

### 3. X1056, X567 분석 요청 텍스트박스
- 배경: `#1A3050`
- 내용: "X1056, X567 para 불량 분석 요청" + scan_data의 집중 LOT/웨이퍼 정보
- 하단 전체 너비 또는 오른쪽 하단
- **독립 영역**

## 이미지박스 ↔ 텍스트박스 분리 원칙

> **핵심 규칙**: 이미지(그래프)가 들어가는 박스와 설명 텍스트가 들어가는 박스는 반드시 별개의 도형으로 분리한다. 겹치거나 같은 텍스트박스 안에 혼재하지 않는다.

| 이미지박스 | 설명 텍스트박스 |
|-----------|---------------|
| SHAP 그래프 박스 | SHAP분석 관련 결과 텍스트박스 (별도) |
| Trend 그래프 박스 | 모델링 결과 텍스트박스 (별도) |
| 대형 이미지박스 (우) | X1056/X567 분석 요청 텍스트박스 (별도) |
| 웨이퍼맵 원형 | Position 버튼 (별도) |

## 데이터 매핑

| 화면 요소 | 데이터 출처 | 없을 때 처리 |
|-----------|-----------|------------|
| 분석시점 | 오늘 날짜 (datetime.now) | - |

| 피처임포턴스 | `importance.features` (feature, lgbm_gain) | "데이터 없음" |
| 불량 현황 | `scan.high_count`, `scan.high_ratio`, `scan.top_lot` | "-" |
| X1056/X567 텍스트 | 고정 텍스트 + `scan.top_lot`, `scan.top_wafer` | - |
